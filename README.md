# CroP — 수능/모의고사 수학 시험지 문항 분할 앱 (macOS)

텍스트 PDF(평가원·사설 모의고사 HWP 출력본)에서 **문제**와 **해설**을 문항 단위로 잘라 600dpi PNG로 저장합니다.

```
crops/
  2606평가원_문제_1공통07.png
  2606평가원_해설_4미적28.png
  연구실모의6회260824_문제_3확통30.png
  ...
```

## 1. 준비 (한 번만)

터미널에서 (이미 하셨다면 건너뜀):

```bash
brew install python-tk@3.12
python3.12 -m venv ~/examcrop
~/examcrop/bin/pip install pymupdf pillow pyinstaller
```

## 2. 실행

**방법 A — 더블클릭 (빌드 불필요, 권장)**
`CroP` 폴더를 원하는 곳(예: 문서)에 두고 `CroP.command`를 더블클릭합니다.
처음 한 번 "확인되지 않은 개발자" 경고가 뜨면 `CroP.command`를 **우클릭 → 열기 → 열기**.
(실행 권한이 풀려 있으면 터미널에서 `chmod +x CroP.command` 한 번.)

**방법 B — CroP.app 만들기 (응용 프로그램 폴더·Dock에 두고 싶을 때)**

```bash
cd CroP폴더
./build_mac.sh
```

`dist/CroP.app`이 생깁니다. 응용 프로그램 폴더로 옮기고, 첫 실행 시 우클릭 → 열기.
(.app은 파이썬을 통째로 담아 100MB 정도이며, 스크립트를 고치면 다시 빌드해야 합니다.)
패치마다 재빌드: `cd ~/Documents/CroP && ./build_mac.sh && rm -rf /Applications/CroP.app && cp -R dist/CroP.app /Applications/`

**방법 C — 터미널**

```bash
~/examcrop/bin/python exam_crop_app.py
```

## 3. 사용법

앱은 Finder처럼 왼쪽 사이드바(시험지 / 결과 PNG / 설정 / 로그)와 위쪽 도구막대, 아래 상태막대로 되어 있습니다.

1. **시험지** 화면에서 `＋ PDF 추가…` → 파일 여러 개를 한꺼번에 선택 (⌘ 클릭 / ⇧ 클릭).
   - 파일명에 `_문제`(또는 `_문`) 가 있으면 문제지, `_해설`(또는 `_해`) 이 있으면 해설지로 인식하고, 이름이 같은 두 파일은 한 세트로 묶입니다.
     예) `K25(260915)_문.pdf` + `K25(260915)_해.pdf` → 세트 `K25(260915)`  (패치 10)
     예) `2606평가원_문제.pdf` + `2606평가원_해설.pdf` → 세트 `2606평가원`
   - 둘 다 없으면 **합본**(문제 뒤에 해설)으로 보고 해설 시작 위치를 자동 감지합니다. 해설이 없으면 문제만 처리합니다.
2. **시험지명**(출력 파일명 앞부분)은 파일명에서 자동으로 만들어집니다. 바꾸려면 표의 시험지명 칸을 **더블클릭**해서 수정 후 Enter.
3. `▶ 문제지 분할`을 누르면 먼저 전체 문항 수를 세고, 아래 상태막대에 **진행 막대 · 완료/전체 문항 수 · 지금 만드는 파일명**이 실시간으로 표시됩니다. 여러 세트는 순서대로 처리됩니다. `■ 중지`로 멈출 수 있습니다.
4. 처리가 끝나면 시험지 표의 상태 칸에 `완료  문제 38 / 해설 38` 처럼 문항 수가 표시되고, 번호가 빠졌으면 `⚠ 누락: 공통 [15]` 로 알려줍니다.
5. **결과 PNG** 화면에서 파일을 체크(✓ 칸 클릭, 또는 선택 후 스페이스)하고 `체크한 파일 이동…` → 목적지 폴더를 고르면 옮겨집니다.
   `탐색기에서 골라 이동…`은 Finder 창에서 파일을 직접 골라(⌘ 클릭) **열기** → 목적지 폴더 선택 순서입니다.
   목적지에 같은 이름이 있으면 덮어쓰지 않고 건너뛴 뒤 알려줍니다. 파일명 더블클릭 → 미리보기로 열림.
6. **설정**: 출력 폴더(기본 `~/Documents/crops`, 모든 결과가 이 한 폴더에 모임), 여백(기본 3mm), DPI(기본 600), 해설을 단 조각으로 따로 저장할지, 기존 파일 덮어쓸지. 자동 저장됩니다.

## 4. 명령줄로도 사용 가능

```bash
~/examcrop/bin/python exam_crop.py 2606평가원_문제.pdf 2606평가원_해설.pdf 연구실모의고사06회_260824.pdf --out ~/Documents/crops
# 옵션: --exam 이름  --margin 3  --dpi 600  --split  --debug(영역 표시 PDF 저장)
```

## 5. 동작 원리와 한계

- 페이지의 긴 가로선(머릿말 밑줄)과 가운데 세로선으로 본문과 좌/우 단을 정하고, 단 왼쪽에 붙은 큰 글자 `N.`(문제 13pt, 해설 20pt 내외)을 문항 시작으로 잡아 다음 문항 직전(또는 단 끝)까지의 글자·수식·그림·도형을 감싸는 사각형을 렌더링합니다.
- `5지선다형`, `단답형`, `확인 사항` 상자, 머릿말/꼬릿말, 흰색 숨은 글자, 해설 앞의 정답표·MEMO·과목 라벨은 제외합니다.
- 해설은 문항 제목이 없는 단의 앞부분을 직전 문항의 연속으로 보고 세로로 이어 붙입니다.
- 과목: 1~22번은 `1공통`, 23~30번은 페이지 머릿말의 과목명(확률과 통계/미적분/기하)으로 `3확통`/`4미적`/`5기하`. 머릿말이 없으면 23번이 다시 나올 때마다 확통 → 미적 → 기하 순.
- **글자를 선택할 수 있는 텍스트 PDF 전용**입니다. 스캔 PDF는 문항을 찾지 못합니다.
- 다른 출판사 양식에서 번호를 못 찾으면 `exam_crop.py` 위쪽의 `PROB_HEADING_SIZE`(12.3) / `SOL_HEADING_SIZE`(17.0)를 낮춰 보세요. 명령줄 `--debug`로 잘린 영역을 확인할 수 있습니다.

## 파일 구성

|---|---|
| `exam_crop_app.py` | GUI 앱 (CroP) |
| `exam_crop.py` | 분할 엔진 + 명령줄 도구 |
| `CroP.command` | 더블클릭 실행 파일 |
| `build_mac.sh` | CroP.app 빌드 스크립트 (PyInstaller) |
| `CroP.icns`, `CroP.png` | 앱 아이콘 |
